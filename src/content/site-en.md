# Tools & Data

Research that stays in a PDF does not change an institution. These are the working artifacts: pipelines, datasets and dashboards built to be used by oversight bodies, journalists and public managers.

## AI-Powered Parliamentary Oversight Auditing System (2026)

An LLM-based pipeline, co-designed with Arthur Leite, that scores Executive replies to parliamentary information requests on five dimensions: completeness, objectivity, timeliness, evidence quality and irregularity signals. It integrates Airtable metadata, local PDF and text extraction, Claude API analysis, validation gates, legal-instrument recommendations and automated Markdown, DOCX and PDF outputs.

*Why it matters:* oversight is usually measured by whether an answer arrived, not by whether it answered. This separates formal compliance from substantive engagement.

Stack: Python · pdfplumber · pyairtable · Anthropic API · python-docx · reportlab · Airtable

## RICs 2019–2024 dataset

13,042 request–response pairs from the Brazilian Chamber of Deputies, with response times, delays and substantive-completeness measures. Underpins the *Public Integrity* manuscript, the MSCA BEYOND proposal, the *Journal of Financial Crime* working paper and both ASC 2026 presentations.

## Radar Aberto de Integridade em Compras Públicas (2026)

A public-procurement risk dashboard built on Brazilian open data for the Office of the Comptroller General's 2nd Open Data Reuse Contest. Covers 30,304 contracts and roughly BRL 59.2 billion, with 32 automated tests.

Five views: overview, attention map, suppliers, agencies, and a methods section. The design deliberately separates the attention index from the strength of the evidence, always shows denominators, includes cases with no signals, and closes every case with a human verification script.

*Status:* completed 18 July 2026. Contest submission pending; deadline 11 September 2026. This is a submission, not an award.

## FIT public dashboards

Public transparency dashboards built for the Parliamentary Front for Oversight, Integrity and Transparency: voluntary federal transfers, PIX budget amendments, authorities' official agendas, and Itaipu Binational agreements and sponsorships.

## Shared Data Lake for congressional offices

An initiative to integrate data assets across congressional offices for oversight, legislative monitoring, communications and strategic decision-making.
